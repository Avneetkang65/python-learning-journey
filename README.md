# Python Practice — Learning Journey

This repository documents my journey learning Python fundamentals through a
structured video course, plus additional self-practice questions I've written
and solved to reinforce each concept.

I'm sharing this publicly to track my progress and stay accountable — expect
regular commits as I keep working through new topics.

## What's covered

| Phase | Topic | What I practiced |
|-------|-------|-------------------|
| 1 | Variables & Data Types | Variable naming rules, `type()`, type conversion |
| 2 | Operators | Arithmetic, comparison, logical, and boolean operators |
| 3 | Built-in Functions | `int()`, `float()`, `str()`, `len()`, `sum()`, `abs()`, `eval()` |
| 4 | Control Flow | `if` / `elif` / `else` statements |
| 5 | Loops | `for` loops, `while` loops, `break`, `continue` |
| 6 | User-Defined Functions | Function definition, arguments, return values |
| 7 | Strings | Indexing, slicing, string methods (`.upper()`, `.replace()`, `.split()`, etc.) |

## How to run any file

```bash
python3 path/to/file.py
```

Some files use `input()` to take values from the user — run them in a
terminal so you can type responses interactively.
